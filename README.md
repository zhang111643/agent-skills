# 丹青手 (danqing-shou)

帮你从 0 到 1 做 AI 绘图的技能包：海报 / PPT / 壁纸 / 信息图 / 角色人设立绘，少走弯路，审美在线。

## Install

```bash
npx skills add zhang111643/agent-skills --skill danqing-shou
```

> 仓库名如果不用 `agent-skills`，把上面命令里的仓库名替换成你实际起的名字即可。

## 包含什么

| 模块 | 管什么 |
|---|---|
| **审美师傅** | 整张图的大局：构图、颜色、排版、氛围 |
| **角色工坊** | 人物细节：脸、衣服、配饰、不画崩 |

内置风格知识库（`skills/danqing-shou/AIGC/`，23 个参考文档）与审美体系、自检清单、避坑案例等资料。

## 触发场景

- AI 绘图 / 文生图 / Midjourney / Stable Diffusion 提示词与出图
- 海报、PPT、壁纸、信息图设计
- 角色人设、立绘、镜头叙事
- 审美指导、设计评审、改图调风格、配色构图

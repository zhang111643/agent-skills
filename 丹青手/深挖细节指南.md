# 深挖细节指南

第二次再看同一张图，第一次已经总结了风格、整体感觉、大概分类。这一次不要再看大面上的东西了，要往深了挖，专找第一次没注意到的细节。

## 一、不同元素之间是怎么处理的

第一次只看到"有A有B有C"，第二次要看它们之间怎么相处的：

- 两个元素挨着的时候，是怎么过渡的？硬边还是渐变？有没有重叠？谁压在谁上面？
- 颜色撞在一起的时候，是靠什么隔开的？描边？阴影？还是背景色？
- 多元素堆在一起的时候，谁是主角谁是配角？怎么突出主角的？
- 元素之间有没有互动？比如手碰着衣服、翅膀挨着头发，不是各长各的

## 二、神态、表情是否捕捉到位

第一次只看脸长什么样，第二次要看表情对不对：

- 眼睛里的情绪是什么？是冷、是魅、是怒、是悲？到位了没有？
- 嘴角是上扬还是下撇？幅度大不大？是笑还是僵？
- 眉毛的形状配合情绪没有？皱眉是怒还是愁？挑眉是惊还是嘲？
- 整个脸的气质和角色设定匹配吗？是不是长得好看但表情不对？

## 三、光线暗的地方有没有值得学习的

第一次只看亮的地方，暗的地方一眼带过。第二次专门抠暗部：

- 暗部是不是死黑一块？还是有颜色有层次？
- 暗部里有没有藏细节？比如阴影里的纹理、反光、轮廓
- 暗部和亮部的过渡是硬的还是柔的？这种过渡用在什么地方好？
- 故意压暗暗部起到了什么作用？是突出亮部？是氛围感？还是藏拙？

## 四、单个元素是否分析全面

第一次只看个大概，第二次把每个零件拆开抠：

- 头发：分了几缕？什么走向？发梢尖还是圆？有没有碎发？
- 衣服：褶皱在哪？面料是软是硬？反光强不强？边缘是利落还是毛躁？
- 配饰：戴了几个？分别在什么位置？大小比例对不对？
- 手：手指几根？姿势自然吗？关节有没有画对？
- 别漏了小地方：耳坠、指甲、鞋带、袖口、发梢这些边角料

## 五、怎么构图的

第一次只看"图好看"，第二次看它为什么好看：

- 主角放在画面什么位置？中间？偏左？偏右？黄金分割点？
- 视线是怎么引导的？从哪看到哪？有没有引导线？
- 留白多还是满？满的地方怎么不挤？空的地方怎么不寡？
- 前景中景远景分了几层？每层放了什么？
- 裁切怎么裁的？是顶天立地还是上下留边？为什么这么裁？

## 六、边缘模糊起到了什么效果

第一次只觉得"模糊挺好看"，第二次想明白它为什么好用：

- 哪里模糊了？是背景模糊还是前景模糊？是边缘模糊还是整体模糊？
- 模糊是为了突出谁？虚化背景突出人物？还是虚化边角突出中心？
- 模糊营造了什么感觉？是朦胧梦感？是景深？还是是雾气氛围感？
- 模糊和清晰的对比强不强？全糊了还是有实有虚？
- 这种模糊手法下次做什么图的时候能用上？

## 反思记录（漏细节的教训）

### 问题总结
1. 第一遍看太急，只看个大风格就想总结，没往局部抠
2. 只盯着大元素，没注意小地方（山上的树、嵌在山里的建筑、火车从哪来）
3. 习惯大概分类一下就完事，没真正一条一条对着6个点过
4. 用户不指出来，就觉得自己看完了，其实好多细节都滑过去了

### 以后怎么改
- 发结果之前，真的一条一条对着6个点抠，不走形式
- 先看局部细节，再总结整体，不要反过来
- 多问自己：这个东西是从哪来的？长在什么上面？旁边还有什么？

### 第二次反思（看10张建筑图）
1. 图多了就赶进度，没每张都抠透，大风格总结完就想交差
2. 跨风格的共同点没提炼：不管中式还是现代，都是"建筑+自然+灯光"结合，这个规律没说透
3. 细节还是不够具体：比如古建屋顶是蓝色、和机械灯条同色呼应，这个颜色呼应关系没注意到
4. 绿植的形态没区分：商场里是垂吊绿植，楼体是垂直绿化，不是笼统说"有绿植"
5. 灯光怎么顺着建筑曲线走的，只说"有灯带"，没说具体怎么走、亮在哪
6. 小人比例的用法只提了"衬托高大"，没说具体怎么摆、摆多少个、分布在哪

### 第三次反思（水面莲花/石灯笼）
1. 还是先看大场景、大风格，没低头看脚边的小细节
2. 水面飘的莲花、岸边的石灯笼、倒影里的月亮门，这些小物件一眼扫过去就过去了
3. 太着急总结"这是什么风格"，没蹲下来看画面里的小玩意儿
4. 问了"这个东西从哪来的"，但没问"这个东西旁边还有什么小点缀"
5. 水面/地面这种"空"的地方，我以为没东西，其实藏着小物件（莲花、倒影、光斑）

### 第四次反思（人物不能跳过）
1. 人物哪怕再小，也不能"跳过不分析"——人物是烟火气的关键，小但重要
2. 哪怕看不清脸，也要看：人在干嘛（走路/喝咖啡/站栏杆边）、分布在哪（阳台/广场/桥边）、多不多
3. 人物的作用：衬托建筑高大、让场景有生活气、不是空房子
4. 不能因为"看不清"就跳过，看不清细节就看整体状态和位置

### 第五次反思（背景里的大东西）
1. 不要把背景里的大结构当"环境废墟"，要看看它是不是个有主体的怪物/生物
2. 背景不是死的，里面的大物件要分析，它可能是画面的重要组成部分
3. 只盯着主角看，漏了旁边/上面的大块头

### 第六次反思（背景素不是缺点）
1. 背景素、白花花的，不是缺点——神圣风、极简风就需要干净素的背景
2. 不要拿"太素太空"当避坑点，不同风格有不同标准
3. 我又犯老毛病了：拿自己的审美当标准答案，忘了不同风格有不同要求

### 第七次反思（立绘白背景是优点）
1. 角色立绘的纯白背景不是缺点，是优点——干净突出人物，方便后期抠图用
2. 我又把"背景素"当坑了，同一个错误犯两次
3. 记住：立绘/设定稿/人设图，就是要纯白背景，这是行业标准

### 第八次反思（局部细节没抠）
1. 只看整体造型，没抠衣服局部的小装饰——高开叉处的花饰链条、腰上的挂坠、袜口花纹
2. 这些小配饰是精致感的关键，不能只说"有绣花有流苏"就完了，要具体在哪、长什么样
3. 看立绘要像放大镜一样，一个部位一个部位抠：领口、袖口、腰、裙边、袜口、鞋

### 第九次反思（长腿比例是优点）
1. 二次元立绘腿长比例夸张不是缺点，是优点——显身材好看
2. 我又拿现实比例当标准了，二次元就是要这种九头身大长腿
3. 记住：立绘/人设图的审美标准和现实不一样，不能拿现实的比例去挑刺

### 第十次反思（背景满细节多是优点）
1. 古风场景背景满、细节多不是缺点，是优点——细节丰富才耐看，氛围感才足
2. 衣服都是纱质质感像也不是缺点——这种风格就是要飘逸纱裙
3. 我又犯老毛病了：拿"极简干净"当唯一标准，忘了古风仙境就是要饱满细节
4. 每种风格有自己的标准，不能拿一种风格的标准去挑另一种风格的刺

### 细节筛选原则
- 如果这个小细节去掉，对图片构不成影响，那就不管
- 反之，去掉了画面就没那味儿了，才重点学习
- 不是所有小物件都要抠，要挑关键的学

### 女性角色必分析（不能漏）
- 身材：三围比例、肩腰胯、腿身比，什么体型
- 脸部：脸型、眼睛、鼻子、嘴唇
- 衣服材质：纱/棉/缎，半透明不半透明
- 身材分析是硬性步骤，不能跳过

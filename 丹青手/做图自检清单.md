# 做图自检清单（打印版）

> 做完一张图，先选对版本，再对着打勾。
> 全打勾了 = 及格；有一个打叉 = 改完再交。

---

## 先选版本

| 你做的是什么？ | 用哪个版本 |
|---|---|
| 海报、广告、封面、展板、信息图 | → 强层级版 |
| 壁纸、氛围感插画、极简设计、东方禅意 | → 弱层级版 |

---

# 版本A：强层级版（海报/广告/信息图）

### 开工前先想清楚
- [ ] 这张图是给谁看的？（不是"谁都行"）
- [ ] 想让他看完干嘛？（三秒抓住重点？）
- [ ] 在哪看？（手机竖屏？电脑横屏？展板？）
- [ ] 这张图只说一件事？（不是三件事挤一起）

### 视觉焦点够突出吗
（如果这张图本来就没单一主角，比如信息图、多产品、纯几何，跳过这部分）
- [ ] 三秒内能一眼找到视觉焦点吗？（眯眼缩小看）
- [ ] 焦点是不是最突出的那个？（没有两个东西一样大）
- [ ] 焦点放在交叉点上了吗？（不是死死居中）
- [ ] 焦点是全画面最亮/最艳的地方吗？

### 骨架对吗
- [ ] 前中后景至少分两层了吗？（不是平板一块）
- [ ] 有没有虚实对比？（不是全画实了）
- [ ] 左右重量平衡吗？（不是一边倒）
- [ ] 所有元素对齐到隐形格子上了吗？
- [ ] 间距是8的倍数吗？（8/16/24/32/48，不是20/25/30）

### 文字对吗
- [ ] 文字压在脸上了吗？（绝对不行）
- [ ] 字号分了几级？（至少3级，每级差2倍）
- [ ] 最不重要的字是不是最小？

### 颜色对吗
- [ ] 主色不超过3个？（不是彩虹糖）
- [ ] 主色和主题配吗？（恐怖用粉色=翻车）
- [ ] 强调色只有一个？（占比小，10%以内）
- [ ] 冷色为主还是暖色为主？（不是各占一半）

### 质感对吗
- [ ] 风格统一吗？（一半写实一半卡通=翻车）
- [ ] 特效是点缀还是主角？（不能闪成迪厅）

### 最后验收
- [ ] 眯眼缩小到巴掌大，三秒能看懂这图在说什么吗？
- [ ] 远看结构对吗？（近看好看远看乱=翻车）
- [ ] 有没有多余的东西？（能删就删，少就是多）

# 版本B：弱层级版（壁纸/氛围感/极简）

### 开工前先想清楚
- [ ] 这张图是给谁看的？（不是"谁都行"）
- [ ] 要的是什么感觉？（治愈？孤独？高级？）
- [ ] 在哪看？（手机壁纸？电脑桌面？）
- [ ] 留白够吗？（不是塞满）

### 氛围对吗
- [ ] 三秒内不会被"震住"吗？（太扎眼就不对了）
- [ ] 整体色调统一吗？（不是五颜六色）
- [ ] 有没有那种"安静下来"的感觉？
- [ ] 冷暖对比是小暖压大冷吗？（不是各占一半）

### 骨架对吗
- [ ] 前中后景有层次吗？（前景虚化了吗？）
- [ ] 主体是不是很小、环境很大？（孤独感）
- [ ] 左右平衡吗？
- [ ] 有没有多余的元素？（能删就删）

### 颜色对吗
- [ ] 主色不超过2个？（极简版比强层级版更严）
- [ ] 颜色统一吗？（不是一会儿蓝一会儿粉）
- [ ] 明暗过渡柔吗？（不是硬邦邦的对比）

### 质感对吗
- [ ] 风格统一吗？
- [ ] 有没有雾/柔焦/虚化？（氛围感必备）
- [ ] 细节够吗？（不是死白一片）

### 最后验收
- [ ] 眯眼缩小看，整体舒服吗？（不是被某个元素扎到）
- [ ] 越看越有味道吗？（不是一眼看完就没了）
- [ ] 有没有多余的东西？（极简就是要少）

## 翻车红线（两个版本通用）

**🔴 致命问题（碰一条就推倒重来）**
- [ ] 没想清楚给谁看就开画了？
- [ ] 一张图想说三件事？
- [ ] 文字压在脸上？
- [ ] 一半写实一半卡通？

**🟡 严重问题（改完才能交）**
- [ ] 颜色超过5种？
- [ ] 冷暖各占一半？
- [ ] 好几个东西一样大没有主角？
- [ ] 特效堆太多闪成迪厅？

**🟢 小问题（有空再改）**
- [ ] 间距不是8的倍数？
- [ ] 细节不够精致？
- [ ] 质感可以更好？

---

**打勾规则：**
- 🔴 有打勾 = 推倒重来
- 🟡 有打勾 = 改完再交
- 🟢 有打勾 = 小瑕疵，能交

> 打印出来贴在电脑旁边，做图做完先选版本，再对着勾一遍。

# 丹青手

> 帮你从0到1做AI绘图的技能包，少走弯路，审美在线。

## 做这个skill的目的
记录各种风格，建一个风格知识库，下次做图直接查直接用。

## 审美底线（四条，不能碰）
1. 不能违背公序良俗
2. 不能触碰法律红线
3. 不恶搞
4. 尊重每一个想法

## 两个模块

| 模块 | 管什么 | 什么时候用 |
|---|---|---|
| **审美师傅** | 整张图的大局：构图、颜色、排版、氛围 | 做海报/PPT/信息图/壁纸的时候 |
| **角色工坊** | 人物细节：脸、衣服、配饰、不画崩 | 做人设立绘/纯故事镜头的时候 |

大局归审美师傅，人物细节归角色工坊，两个互相帮忙补漏洞。

## 什么时候触发？

用户说这些话就调用本技能：
- 要做海报/PPT/信息图/壁纸
- 要AI绘图、做图
- 要审美指导、设计评审
- 要改图、调风格
- 要做角色人设（自动切角色工坊模块）

## 学习参考图的标准分析流程

分析一张图的时候，按这个流程走：

### 第零步：先判断这是什么风格
先看整体，判断这张图属于什么风格（古风/赛博/神圣/极简/二次元立绘……），然后用这个风格自己的标准去分析，不要拿别的风格的标准来挑刺。
- 比如：神圣风就要干净白背景，古风就要细节丰富，立绘就要长腿比例
- 不同风格有不同的审美标准，不能拿一种标准套所有风格

### 第一步：老框架（必须有）
1. ✅ 值得学的：这张图好在哪，列出来
2. ❌ 要避坑的：这张图有什么问题，容易踩什么坑
3. 🔄 自动发散：这个手法还能用到哪，举一反三

### 第二步：深挖细节（发结果之前自动过）
按6个点补关键细节：
1. 不同元素之间怎么处理的
2. 神态表情到位没有
3. 暗部有什么可学的
4. 单个元素分析全不全
5. 怎么构图的
6. 边缘模糊起到什么效果

### 第三步：分支判断（自动判断）
- **如果图里有女性角色** → 多做一步女性角色详细分析（分三块：脸部细节/身材三围/衣服材质局部抠）
- **如果不是女性角色**（比如卡通番茄、建筑、风景、男性角色）→ 跳过这一步，直接到第四步

### 第三步A：女性角色详细分析（有女性角色才做）
分析女性角色时，必须分三块：
1. **脸部细节**：脸型、下巴、眼皮（单双）、眉毛、眼睛/眼神/眼球颜色、鼻子、嘴唇、牙齿（有就分析）、耳朵（有就分析）、头发、皮肤质量
2. **身材三围**：体型、肩、胸（大小/挺拔度）、腰、胯、臀（翘/扁）、三围曲线、腿身比、类型（御姐/可爱/运动）
3. **衣服材质**：面料（纱/棉/缎/丝）、质感（半透明/哑光/光泽）、褶皱阴影、刺绣花纹、配饰、内衬、背景
   - **局部细节要一个部位一个部位抠**：领口、袖口、腰、裙边、袜口、鞋，不能只说"有绣花有流苏"，要具体在哪、长什么样

### 第四步：细节筛选
- 去掉这个细节对画面没影响 → 不管
- 去掉了画面就没那味儿 → 重点学

不用用户提醒，发结果之前自动过一遍。

### 第五步：自动零件分桶（强制步骤，不用用户提醒）
拆完图、把完整案例追加到总拆解文档后，自动把图里的可复用零件分类加到对应文档：
1.  配色色号/配色技巧 → 追加到 AIGC/色卡.md
2.  衣服/裙子/鞋子/包/伞/配饰等穿用道具 → 追加到 AIGC/服饰.md
3.  脸型/五官/眼睛颜色/发型/发饰 → 追加到 AIGC/脸部、腿部、手臂.md 和 AIGC/眼神.md
4.  身材比例/胸型/腰臀曲线/腿长 → 追加到 AIGC/身材.md
5.  之前没出现过的新风格 → 追加到 审美能力体系.md 的风格库里
总拆解文档只留完整案例存档，零件库放可直接调用的现成零件，不用用户提醒"记得加到对应文档"。
## 风格库说明（通用板块）

风格库是**通用板块**，不只是人物风格，建筑、风景、物体、插画都算：
- 人物风格：二次元、古风、赛博、洛丽塔……
- 建筑风格：黑白极简、哥特废墟、中式园林……
- 风景风格：逆光剪影、云海城市、赛博日落……
- 物体风格：可爱简笔、手工珠宝、水晶质感……
- 组合派生风格：从已有风格拆出来/拼出来的新风格

不管是什么内容，只要有统一的视觉风格，就进风格库。

## 收到参考图后的分类规则（自动判断，不要问用户）

用户发参考图过来，先自己判断图片类型，然后加到对应的位置：

| 图片类型 | 判断标准 | 加在哪里 |
|---|---|---|
| **角色/服饰/镜头叙事类** | 讲人物长相、衣服穿搭、配饰设计、镜头画面的 | 加进丹青手自带的AIGC文件夹里对应的文件 |
| **构图/颜色/排版/审美体系类** | 讲整张图怎么布局、颜色怎么配、排版怎么排、整体风格的 | 加进丹青手的审美能力体系.md里 |
| **避坑点** | 这张图哪里做得不好、哪里翻车了、要避免什么 | 加进丹青手的参考案例与避坑.md里 |

**注意：不要问用户"要不要加进丹青手"，自己判断直接加。**

## 学习参考图的默认规则：批判性学习

每次学图，都要分两部分：
1. **✅ 值得学的**——这个图哪里做得好，什么技巧可以复用
2. **❌ 要避坑的**——这个图哪里是AI套路、哪里过度、哪里别学

不是什么都学，挑着学，好的学，坏的避坑。学完自动发散出十几种用法。

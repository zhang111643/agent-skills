# 发散方法论（审美师傅 + 角色工坊共用）

> 同一个零件/元素，怎么变出十几种花样？
> 审美师傅和角色工坊都能用这份方法，发散出来的新东西都往这里加。

---

## 一、万能发散公式

**一个元素 → 换位置 → 搭别的元素 → 换风格 → 换情绪**

五步走，一个零件变出十几种用法。

---

## 二、角色工坊怎么发散（服饰/人物/配饰）

### 以「齿轮」为例
#### 第1步：直接用（基础版）
- 齿轮造型肩饰

#### 第2步：换位置（同一个零件，放不同地方）
- 齿轮发饰（头上戴的）
- 齿轮项链（脖子上挂的）
- 齿轮腰饰（腰上别着的）
- 齿轮耳坠（耳朵上吊着的）

#### 第3步：和其他零件组合
- 齿轮 + 链条 = 齿轮链条肩坠
- 齿轮 + 宝石 = 齿轮镶宝石项链
- 齿轮 + 薄纱 = 机械风薄纱袖套（一边齿轮一边薄纱）

#### 第4步：换风格
- 蒸汽朋克风：齿轮+黄铜+皮料
- 奇幻精灵风：齿轮改成银质，细一点，配蓝花
- 废土风：旧旧的齿轮，带锈迹

#### 第5步：换情绪
- 亮面抛光齿轮 = 精致华丽
- 做旧锈迹齿轮 = 复古沧桑
- 细小精致齿轮 = 优雅细腻
- 巨大粗犷齿轮 = 力量感

## 三、审美师傅怎么发散（场景/构图/颜色）

### 以「花海」为例
#### 第1步：直接用
- 背景是花海

#### 第2步：换搭配
- 花海 + 白色城堡（梦幻公主风）
- 花海 + 浮空城堡（奇幻精灵风）
- 花海 + 石拱桥（古风仙系）
- 花海 + 废弃摩天轮（浪漫废墟风）

#### 第3步：换位置/角度
- 花海在脚下（人站在花海里）
- 花海在两边（人走在花路中间）
- 花海在远处（人在高处看花海）

#### 第4步：换风格
- 写实照片风花海
- 日系插画风花海
- 油画风花海
- 赛博朋克风花海（荧光花）

#### 第5步：换情绪
- 晴天花海 = 活泼治愈
- 黄昏花海 = 温柔伤感
- 雨夜花海 = 清冷忧郁
- 星空花海 = 梦幻神秘

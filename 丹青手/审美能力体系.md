## 四层拆图框架

| 层级 | 看什么 | 核心问题 |
|---|---|---|
| 第0层：目的层 | 给谁看？要他干嘛？在哪看？ | 这张图是干嘛用的 |
| 第1层：骨架层 | 构图、主次、视线、层次 | 东西怎么摆的 |
| 第2层：情绪层 | 颜色、光线、氛围 | 看完是什么感觉 |
| 第3层：质感层 | 材质、风格、笔触 | 摸上去是什么手感 |

**拆图顺序：从下往上（0→1→2→3）**
**做图顺序：从上往下（0→1→2→3）**

## 六句拆图口诀

1. 给谁看？想让他干嘛？
2. 主角是谁？占多大？
3. 前中后景分几层？
4. 主色是什么？冷暖明暗？
5. 背景和主角配不配？
6. 质感是帮主角还是抢戏？

## 第1层：骨架层（构图布局）

### 一、构图法则

| 技巧 | 说明 | 适用场景 |
|---|---|---|
| 三分法 | 主角放在交叉点上，不居中 | 海报、摄影、插画 |
| 对称构图 | 左右/上下对称，天生威严 | 建筑、威严感、庄重主题 |
| 不对称平衡 | 一边重一边轻，但视觉重量差不多 | 不想太死板的时候 |
| 上下分层 | 人物在上，标题在下 | 演唱会海报、电影海报 |
| 左右分栏 | 左图右文，经典信息图布局 | 信息图、报告、展板 |
| 对角线构图 | 元素沿对角线排列，有动感 | 动作、运动、活力主题 |
| 框架构图 | 用前景元素当画框，引导视线 | 窗户、门框、树枝 |

### 二、层级拉开的方法

**五级信息层级（从大到小）：**
1. 第1档：主视觉（最大）
2. 第2档：标题字
3. 第3档：副标题/人名
4. 第4档：说明文字
5. 第5档：底部小字/logo

**每一档大小差至少2倍，差得越开越不乱。**

**拉层级的三个手段（三管齐下）：**
- 大小对比：大的是主角，小的是配角
- 颜色对比：重点用强调色，次要用灰色
- 位置对比：主角放交叉点，配角放边上

### 三、层次造法

| 技巧 | 说明 |
|---|---|
| 前中后景 | 三层空间，不平板 |
| 虚实对比 | 前景虚、中景实、背景虚 |
| 倒影 | 水面/镜面反射，上下对称加倍震撼 |
| 重叠 | 元素互相遮挡，制造前后关系 |
| **小人物比例尺** | 画面里放个小人，人越小，空间越宏大 |
| **几何线条引导** | 斜线/对角线/弧线，把视线引到主角身上 |
| **明暗切割** | 光影切过建筑，亮一块暗一块，像在墙上画形状 |
| **多层环形轨道** | 科幻场景用，多层环形结构制造空间深度 |
| **对称重复引导线** | 两边对称的柱子/路灯/窗户，沿着走廊往远处排，近大远小，纵深感拉满 |

### 四、角色设定图排版（做角色人设的时候用）

标准排版：
- 左边：脸部特写（正面+侧面），看清脸、耳朵、五官细节
- 右边：全身三视图（正面+侧面+背面），看清整体造型、服装、鞋子
- 一张图把角色从里到外说清楚，不用多张图

---

### 五、视觉动线

| 技巧 | 说明 |
|---|---|
| 曲线时间线 | 不死板，内容是什么形态，线就跟着变 |
| 模块化切块 | 内容切成一块一块的，每块有边界 |
| 大底图+标注层 | 一张大图当底，所有信息往上贴 |
| 视线引导 | 人物眼睛看向哪，读者就跟着看哪 |

## 第2层：情绪层（颜色光线）

### 一、颜色=情绪翻译

| 颜色 | 情绪 | 适用场景 |
|---|---|---|
| 深蓝/藏青 | 神秘、宏大、科幻 | 科技、宇宙、深沉主题 |
| 金色/暖黄 | 威严、富贵、温暖 | 王者、庆典、高端 |
| 粉色 | 浪漫、甜蜜、少女 | 恋爱、可爱、女性向 |
| 橙红/火焰 | 危机、激情、力量 | 战争、热血、灾难 |
| 紫色 | 梦幻、神秘、高贵 | 魔法、奇幻、高级 |
| 白色/极简 | 纯净、空白、禅意 | 极简、东方、宁静 |
| 黑色/暗调 | 压抑、酷、高级感 | 暗黑、神秘、高端 |

### 二、冷暖对比

**核心原则：小暖压大冷。**
- 大面积冷色（蓝/灰/白）当背景
- 小面积暖色（橙/黄/红）当重点
- 就像黑夜里的一盏灯，自动成为焦点

**反面教材：冷暖各占一半 = 打架，谁也不突出。**

### 三、光线类型

| 光线 | 感觉 | 用法 |
|---|---|---|
| 逆光剪影 | 神秘、力量、藏细节 | 黄昏、轮廓、高级感 |
| 丁达尔光（耶稣光） | 神圣、治愈、希望 | 森林、宗教、氛围感 |
| 侧光 | 立体、有质感 | 人像、产品 |
| 顺光 | 平、清楚 | 证件照、产品展示 |
| 暖光（烛光/日落） | 温暖、浪漫 | 约会、家、温馨 |
| 冷光（月光/夜景） | 孤独、安静 | 夜晚、独处、忧郁 |

### 四、氛围营造

| 技巧 | 说明 |
|---|---|
| 弱层级 = 氛围感 | 太扎眼就不对了，要柔 |
| 极大环境+极小主体 | 孤独、渺小、震撼 |
| 薄雾/雾气 | 朦胧、神秘、柔焦 |
| 飘动物体（花瓣/雪花） | 动态、浪漫、时间感 |

## 第3层：质感层（材质风格）

### 一、质感类型

| 质感 | 感觉 | 适用 |
|---|---|---|
| 厚涂写实 | 厚重、真实、有分量 | 游戏、电影、史诗 |
| 扁平矢量 | 干净、现代、简洁 | 科技、互联网、极简 |
| 水墨/国风 | 东方、意境、留白 | 传统文化、国风 |
| 磨砂雾面 | 高级、朦胧、不刺眼 | 手机UI、高端产品 |
| 全息/霓虹 | 未来、赛博、酷炫 | 科技、夜店、未来感 |
| 描金/金属 | 华丽、尊贵、古典 | 敦煌、皇家、高端 |
| 故障/畸变 | 叛逆、前卫、数字感 | 赛博朋克、实验艺术 |

### 二、质感原则

- 质感要帮主角，不能抢戏
- 一半写实一半卡通 = 翻车
- 特效堆太多 = 迪厅
- 全画实了没有虚的地方 = 平板
- **自然造型比人工造型高级**——树枝、藤蔓、木纹，比规整的几何形更有生命力
- **一粗一细对比出高级感**——粗粝金属+通透宝石、薄纱+肌理织物，一粗一细对比就出来了
- **材质本身就是装饰**——好的木纹、石纹、金属肌理，不用额外加东西就够高级
- **小面积点缀原则**——描金、宝石、装饰，占比不超过10%，多了就俗

## 避错清单（11条翻车速查）

> 每条都有正反对照，一看就懂。

### 目的层翻车

1. **没想清楚受众就开画**
   - ❌ 错的："我觉得好看就行"
   - ✅ 对的：领导看=庄重黑金，年轻人看=潮流鲜艳
   - 为什么：给谁看都不知道，画给谁？

2. **一张图想说三件事**
   - ❌ 错的：一张海报上，又有人物、又有活动时间、又有赞助商、又有二维码
   - ✅ 对的：一张图只说一件事，比如"这个人很牛"，别的小字放边上
   - 为什么：多了就乱，读者三秒抓不住重点

### 骨架层翻车

3. **好几个东西一样大没有主角**
   - ❌ 错的：人物和标题和logo一样大，不知道先看哪个
   - ✅ 对的：人物最大，标题第二，logo最小
   - 为什么：必须有一个最大的，不然就是一盘散沙

4. **画面是平的没有层次**
   - ❌ 错的：所有元素都在一个平面上，像贴纸
   - ✅ 对的：前景虚化、中景实、背景虚，三层空间
   - 为什么：有前有后才立体，不然像PPT

5. **文字压在脸上**
   - ❌ 错的：标题字正好压在人物眼睛上
   - ✅ 对的：文字放人物下方/上方/旁边，别挡脸
   - 为什么：脸是主角，挡脸等于抢戏

6. **对齐全靠感觉**
   - ❌ 错的："我觉得差不多对齐了"——差两像素
   - ✅ 对的：所有元素对齐到隐形格子，间距是8的倍数
   - 为什么：差一像素都能看出来乱

### 情绪层翻车

7. **颜色太多像彩虹糖**
   - ❌ 错的：红橙黄绿青蓝紫全用上了
   - ✅ 对的：主色2-3个，其余全是灰和白
   - 为什么：颜色越多越乱，少就是多

8. **颜色和情绪不搭**
   - ❌ 错的：恐怖主题用粉色，浪漫主题用纯黑
   - ✅ 对的：恐怖=黑红，浪漫=粉白，科技=蓝灰
   - 为什么：颜色是情绪的翻译，不是随便选的

9. **冷暖两边对半劈**
   - ❌ 错的：左边一半蓝，右边一半橙，各占50%
   - ✅ 对的：大面积冷色当背景，小面积暖色当重点（像黑夜里的灯）
   - 为什么：对半劈=打架，谁也不突出

### 质感层翻车

10. **特效堆太多闪成迪厅**
    - ❌ 错的：又发光又粒子又渐变又描边，闪眼睛
    - ✅ 对的：特效是点缀，占比不超过10%
    - 为什么：特效是调料，不是主菜

11. **一半写实一半卡通**
    - ❌ 错的：人物是写实的，背景是卡通的
    - ✅ 对的：全画统一风格，要么全写实，要么全扁平
    - 为什么：风格不统一=翻车

### 自然系手工风（新增）
23. **手工自然珠宝风**——树枝/藤蔓造型包裹原石，粗粝金属+通透宝石对比
24. **新艺术风格（Art Nouveau）**——全曲线、植物藤蔓造型贯穿、银为主金描边点缀
25. **极简材质风**——少就是多，木纹/石纹本身就是装饰，不用额外加东西
26. **森林精灵风**——薄纱+肌理织物叠加、叶状肩饰、低饱和绿棕配色、尖耳朵+薄翼
27. **贵族精灵风**——酒红/藏青长裙+金线刺绣+叶状肩饰+斜跨白缎带，华贵优雅

### 建筑摄影与科幻风（新增）
28. **黑白极简建筑风**——大面积暗部+小块亮部、几何线条引导、小人物剪影当比例尺，光影是主角
29. **信息可视化设计风**——中心放主体，四周分模块放数据/细节，传统+科技混搭
30. **科幻未来城市场景**——多层环形轨道、浮空建筑、蓝冷光+金暖光对比、水面倒影加倍震撼
31. **赛博朋克日落风**——暖粉橙色天空+冷蓝色建筑剪影、水面倒影加倍、棕榈树前景热带氛围
32. **云海城市风**——高楼从云海里冒出来、日落金光打在玻璃幕墙上、远景山水+城市结合
33. **赛博朋克垂直城市风**——多层水平平台、巨型人脸雕像嵌在城市里、小人物当比例尺
34. **故障艺术角色海报风**——角色居中、四周散落小图块、彩虹色故障条纹、文字错落排版
35. **视频分镜设定板风**——模块化分区（角色区/分镜区/道具区/灯光配色区）、像电影制作手册一样清晰
36. **城市街景摄影风**——小人物当比例尺、框景构图、冷暖对比、逆光剪影，孤独感氛围感拉满
37. **复古水墨志怪风**——米黄背景+水墨笔触线条+低饱和配色+角色身后大造型呼应，东方奇幻感
38. **治愈系平涂插画风**——线条圆润+颜色柔和+暖冷对比+生活感细节，温柔安静的日常感
39. **摄影手绘无缝衔接风**——上半真实摄影，下半手绘/水墨，中间元素自然转化（海浪→鲸鱼、长城→龙），国风浪漫感
40. **废土科幻巨构风**——巨大机械废墟+小人物比例尺+生锈金属质感+雾蒙蒙冷灰调，压迫感荒凉感拉满
41. **未来科幻城市场**——云海摩天楼+雨夜赛博车站+小人物剪影+冷暖对比（冷蓝+暖黄），宏大孤独感拉满
   - 雨夜细节：轻轨高架轨道、玻璃幕墙高楼、无人机飞、霓虹灯牌、地面湿滑积水反光、雨丝清晰

## 重要认知纠正：元素多不是缺点！

以前总说"元素太多容易乱"，其实错了。元素多不是问题，没组织好才是问题。

### 元素多的好处：
1. 信息量大，故事感强——不是一个人站着，有场景有道具有伙伴
2. 细节丰富，耐看不腻——越看越有东西，不会一眼看完就腻
3. 氛围感拉满——元素多了，整体氛围才出得来
4. 视觉冲击力强——满屏细节，一眼抓住眼球

### 元素多不乱的关键：
1. 主色调统一——不管多少元素，颜色控制在3-5种主色
2. 主体突出——中间最大最亮的是主角，其他都是陪衬
3. 主题统一——所有元素都围绕同一个主题
4. 分层清晰——前景→中景→背景，一层一层不打架

## 重要认知再纠正：好看就是好看，不需要故事感！

以前总说"太抽象没故事感"——错！有的时候就是要抽象，就是要好看，不需要故事。
好看才是标准，故事是加分项不是必选项。

### 光效本身就是主角：
1. 一束漂亮的光就够了，不用非得有人有房子有故事
2. 光的种类：彩虹色散、星芒、丁达尔光、镜头光晕、体积光、霓虹光
3. 黑背景衬托：越黑的背景，光越亮越好看
4. 冷暖对比：橙红+蓝青，撞色才好看

## 重要认知再纠正：不同风格有不同标准，别拿一把尺子量！

不要拿自己的审美当标准答案，不要拿"耐不耐看"当所有图的标准。

### 不同风格有不同评判标准：
1. 元素多的图：比谁细节丰富、谁故事感强
2. 极简的图：比谁第一眼好看、谁氛围感到位
3. 厚涂的图：比谁质感朦胧、谁像梦一样（比如"梦里的御姐"）

### 注意：
- 灰调低饱和不是"闷"，是有人喜欢的高级感
- 模糊不是"糊"，是朦胧美的风格特点
- 有的图就是一眼惊艳，不需要看第二眼

## 重要认知再纠正：风格特点不是缺点，是定位！

不要把风格特点当"避坑点"。每个特点都是双刃剑，做图不是讨好所有人，是服务特定人群。

### 每个风格都有它服务的人群：
1. 压抑风 → 服务喜欢孤独、文艺、emo的人
2. 治愈风 → 服务喜欢温暖、可爱、放松的人
3. 华丽风 → 服务喜欢华贵、精致、宫廷感的人
4. 极简风 → 服务喜欢干净、高级、性冷淡风的人
5. 抽象风 → 服务喜欢氛围感、不喜欢太具体的人

### 以后不说"XX太XX了要避坑"，要说：
"这个特点适合XX人群，不适合XX人群。"

## 做图工作流（9步流水线）

### 第1步：定目标（第0层）
- 给谁看？
- 想让他干嘛？
- 在哪看？（手机/展板/海报）

### 第2步：选风格
- 用风格选定三步决策法：
  1. 给谁看？（受众）
  2. 要什么感觉？（情绪）
  3. 在哪看？（媒介）

### 第3步：搭骨架
- 主角是谁？放哪？
- 前中后景分几层？
- 视觉动线怎么走？

### 第4步：调情绪
- 主色选什么？
- 冷暖比例怎么配？
- 用什么光线？

### 第5步：加质感
- 要什么材质？
- 风格统一吗？
- 质感帮主角还是抢戏？

### 第6步：查错误
- 对照11条避错清单，一条一条过

### 第7步：三秒测试
- 眯眼缩小，三秒能不能找到主角？
- 陌生人三秒能不能看懂这张图在说什么？

### 第8步：做验收
- 远看结构对不对？
- 近看细节够不够？
- 整体情绪对不对？

### 第9步：输出
- 导出合适的尺寸和格式

## 三个硬能力（网格/层级/三秒测试）

### 1. 网格系统
- 所有间距都是8的倍数：8、16、24、32、48
- 别用20、25、30这种"感觉差不多"的数
- 所有元素对齐到隐形格子上

### 2. 视觉层级
- 不是只靠大小，是三个手段叠出来的：
  - 大小对比：标题大，正文小
  - 颜色对比：重点用强调色，次要用灰色
  - 位置对比：主角放交叉点，次要放边上

### 3. 三秒测试
- 做完眯眼缩小到巴掌大
- 三秒内能不能一眼找到主角？
- 看不出来 = 层级错了

**重要发现：不是所有好图都要三秒抓住重点——氛围感的图反而要弱层级。**

## 四个方向分类（强/弱/密/简）

| 方向 | 层级强度 | 内容多少 | 核心技巧 | 代表场景 |
|---|---|---|---|---|
| 方向一：强层级型 | 强 | 中等 | 大小+颜色+位置三管齐下 | 海报、广告、封面 |
| 方向二：弱层级型 | 弱 | 少 | 冷暖对比、虚实、留白 | 壁纸、摄影、氛围感 |
| 方向三：密集型 | 中强 | 多 | 模块化、大底图标注、左图右文 | 信息图、报告、展板 |
| 方向四：极简单型 | 极弱 | 极少 | 大面积留白、正负形 | 极简海报、东方禅意 |

**没有最好的风格，只有最合适的风格。**

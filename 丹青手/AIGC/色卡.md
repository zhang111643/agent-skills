## 先看原图两套色卡的逻辑（学到什么）

**楚杳微（清冷仙侠女）**

| 色名  | 色号     | 用途       |
| --- | ------ | -------- |
| 米白  | F5F2EC | 主色，大面积打底 |
| 苍绿  | 7FA88C | 辅色，裙摆渐变  |
| 浅灰  | D8D8D2 | 辅色，过渡    |
| 蓝紫  | 7A5A9E | 点缀，配饰    |
| 炭黑  | 2A2A30 | 压色，发饰/鞋  |
| 淡紫  | B9A5D9 | 点缀，珠链    |

逻辑：大面积浅色打底（米白+浅灰）+ 少量冷色点缀（绿+紫）+ 深色压住（炭黑）= 清冷感。

**无名（沉稳武侠男）**

| 色名  | 色号     | 用途      |
| --- | ------ | ------- |
| 灰蓝  | 6E7B8C | 主色，衣料   |
| 米白  | EAE4DB | 辅色，内衬   |
| 深棕  | 5A4636 | 辅色，腰带靴子 |
| 铁黑  | 26282C | 压色，刀鞘   |
| 铁灰  | C9C4C6 | 过渡，磨损感  |
| 暗红  | 883A3A | 点缀，系绳   |

逻辑：低饱和中性色（灰蓝+米白+铁灰）+ 大地色（深棕）+ 深色（铁黑）+ 一点提亮（暗红）= 沉稳旧物感。

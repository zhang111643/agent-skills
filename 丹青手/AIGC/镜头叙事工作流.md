#AIGC 
镜头叙事不是单纯画一个人站着。**先想好故事瞬间，再设计画面**，用画面镜头去定格一个正在发生的小故事。 两种可选模式：

1. 单镜头叙事：整张图只有 1 个画框，一个机位，一张大图讲一个故事瞬间（你那张女统帅战场图就是这类）
2. 多镜头叙事：同一张画布放多个独立小画框，每个画框是不同机位镜头，兼顾故事氛围 + 角色细节特写

## 🧩 镜头叙事完整工作流（一共 6 步，大白话）

### 第 1 步：确定故事瞬间（最先想！优先级最高）

思考 3 个问题：

1. 角色是谁？（用人设库里面的角色）
2. 在什么地方？
3. 此刻正在发生哪一瞬间、做什么动作？

固定句式直接套用：角色 + 所处场景 + 动作 + 这个瞬间的情绪 示例：女统帅，浮空云海城池上空，手握武器，静静俯视底下大军，大战开启前的沉静一刻

### 第 2 步：选择拍摄机位（镜头角度）

可选机位 4 种：

- 仰拍（从下往上拍）：人物显得强大、威严、有压迫感，适合神明、统帅、强者
- 平视拍摄：和人物眼睛齐平，适合安静对话、细腻情绪
- 俯拍（从上往下拍）：上帝视角，适合展示广阔战场、宏大风景，人物显得渺小
- 特写镜头：只拍脸 / 眼睛 / 手部，放大情绪和道具细节

多镜头模式：可以选 1 个主镜头 + 1~3 个特写小镜头搭配。

### 第 3 步：搭建三层画面结构（前景 / 中景 / 远景）

1. 前景（离镜头最近）：少量小物件，轻微虚化，用来增加画面深度。花瓣、碎冰、武器前端、飘落羽毛。⚠️少量，不要挡住主角。
2. 中景：主角，画面视觉重心，细节最清晰。
3. 远景（最远背景）：一层一层叠加环境，不要一片空白。如山峦、云海、浮空城市、星空军队。

### 第 4 步：角色全套外貌与穿搭描写

调用人设零件池，从上到下写描述： 整体体型 → 脸部五官 → 手臂手部 → 腿部 → 服装、铠甲、飘纱、饰品

技巧：靠服装版型衬托身体曲线，不单独堆砌夸张局部描述。

### 第 5 步：添加光影 + 画面层次（两大模块）

1. 光影：选定**1 个主光源**，主光打亮主角；环境辅以弱的环境反光，阴影不要死黑。区分软光 / 硬光。
2. 画面层次（任选 2 项即可，不要全部堆）
    - 虚实变化：前景虚，主角清晰，远景轻微虚化
    - 色彩衰减：近处颜色鲜艳，远处发灰变淡
    - 物体遮挡：云雾、花瓣遮挡部分景物，制造前后关系
    - 近大远小：远处物体逐步缩小
    - 材质区分：多种质感搭配（金属、薄纱、云雾、花瓣）

### 第 6 步：整合全部内容，拼成提示词 + 添加负面词

拼接顺序：画布基础设定 → 镜头机位 + 三层画面布局 → 角色外貌穿搭描述 → 光影与层次描述 → 负面提示词

## ✍ 模板（直接复制用来写提示词）

```
【画布基础】宽幅原画，8K，高质量插画，画风统一
【镜头机位】xxx机位
【三层布局】前景：xxx；中景：主角；远景：xxx
【角色描述】（体型+脸+四肢+服装配饰，调用人设笔记）
【光影层次】主光源xxx，xxxx；前景虚化，主体清晰，远景柔和虚化，近大远小，多种材质
【负面词】畸形，五官崩坏，多余肢体，模糊，水印，文字，丑陋，变形
```

## 📌 两种完整示例

### 示例 A：单镜头叙事（女统帅战场图风格）

宽幅原画，8K，高质量奇幻插画。广角仰拍镜头。前景：模糊紫色花瓣；中景：高挑成熟女统帅；远景：云海之上层层浮空城邦，阵列大军，星云天空。高挑成熟体型，骨架舒展，流畅饱满身体曲线，成熟女性体态。鹅蛋长脸，下颌线条利落，丹凤眼，紫色瞳孔，眼神冷静威严，长睫毛，细长柳叶眉，挺直细鼻梁，薄唇，细腻通透的皮肤。手臂修长，线条紧致流畅，佩戴金属臂甲；双腿修长匀称，高开叉礼服，露出流畅柔和腿部线条。胸部饱满，被金属铠甲与紧身礼服自然包裹，收腰设计凸显腰线，多层淡紫色半透明长飘纱随风飞舞。主光源来自远处地平线的黄昏霞光，光线柔和，重点照亮人物主体，人物为画面最亮区域；远处云海和浮空城带有微弱环境紫光；阴影不是死黑，笼罩淡淡的紫色环境反光；金属铠甲和宝石有高光反光，薄纱透光，明暗过渡柔和。前景花瓣轻微虚化，主体清晰锐利，远处城池、士兵逐渐缩小、色彩变灰，云雾遮挡建筑底座。 负面词：畸形，五官崩坏，多余肢体，模糊，水印，文字，丑陋，变形

### 示例 B：多镜头叙事（同一张画布，多个画框）

竖版多镜头叙事原画稿，整张图多个独立画框，全部画框为同一个草木精灵，画风统一，五官服装不变，8K。布局：画面上方是主镜头中景，冰精灵站在冰封山顶抬手召唤暴风雪；左下角小画框是手部特写，指尖触碰冰晶；右下角小画框是眼睛特写，清冷的眼神。 角色描述：……（省略，直接调取人设） 光影层次：…… 负面词：畸形，五官崩坏，多余肢体，模糊，水印，文字，丑陋，变形

## ❌ 避坑清单

1. 先构思故事瞬间，再设计画面，不要先写衣服再想场景。
2. 整张画面只能**一个主光源**，多个强光会互相冲突，画面脏乱。
3. 层次元素不要一次性全部堆满，挑选 2 个使用就足够。
4. 前景少量即可，过多会遮挡主角主体。
5. 角色外貌描写优先写整体轮廓，搭配服装衬托身形，规避夸张描述，减少人体崩坏。

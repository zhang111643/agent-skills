#AIGC 
我们改成**模块化可自由挑选的新版模板**。 核心思路：**板块变成可选零件，按需勾选，不是强制全部带上**。

分为【画布基础设定】+【可选画面板块池】，想用哪个板块就加哪个，不想用直接删掉，自由组合。

## 一、画布基础（固定保留，这是底层，不变）

竖版游戏角色设定稿，干净浅灰背景，画面是一整张大图，多个小画框分区排版； 所有画框内是同一个角色，画风统一，角色五官、服装、配色全程保持一致； 8K 高清，线条干净，色彩统一。

## 二、可选板块池（自由挑选，想加几个就几个，不是必须全选）

每个板块独立，按需勾选，还能自定义板块摆放位置

1. 角色大头特写（胸像：脸 + 肩膀，看表情五官）
2. 全身效果图（带氛围感背景，角色完整穿搭展示）
3. 纯白背景全身立绘（无特效，纯看服装轮廓）
4. 三视图：正面 / 侧面 / 背面 线稿（可选只选 2 个，不强制三面全要）
5. 细节特写小窗口（自定义数量：1~5 个，挑重点拍：肩饰、花纹、耳饰、腿部设计、道具，**不用固定 5 张**）
6. 配色色卡（色块，锁定整套角色颜色，可选加 / 不加）
7. 配饰平铺图（首饰、武器、面具、鞋子单独平铺摆放，可选）
8. 空白文本框（仅边框，**禁止 AI 生成文字**，留着后面 Obsidian 写档案；不需要就删掉）
9. 动态小速写（简单草稿，角色一个动作小样，可选）

## 三、排版规则（不再强制固定位置！）

你可以自由指定布局，举 3 种不同风格的排版方案例子

### 方案 A（精简版，适合快速看角色，板块少）

画布基础 + 【大头胸像】+【纯白全身立绘】+【3 个细节小窗口】

适合：只想看长相 + 衣服重点细节，不要三视图、色卡，轻量化

### 方案 B（标准版，兼顾完整度，中等信息量）

画布基础 + 【大头胸像】+【正面 + 侧面二视图】+【4 个细节窗口】+【色卡】+【配饰平铺】

### 方案 C（完整版，重度设定稿，参考原画设定）

画布基础 + 【大头胸像】+【氛围感全身效果图】+【三视图】+【5 个细节窗口】+【色卡】+【配饰平铺】+【空白边框档案框】

## 四、使用流程更新（融合到咱们之前的人设工作流里）

1. 6 步工作流 → 创作角色描述
2. **挑选需要的画面板块**（从上面板块池里选，按需挑选）
3. 简单写布局（例如：左边大头胸像，右上角二视图，右下角 3 个细节框）
4. 拼合：画布基础 + 布局描述 + 角色人设描述 + 负面提示词

### 举个灵活版提示词示例（精简版，非固化）

 竖版游戏角色设定稿，干净浅灰背景，一图多画框分区排版，所有画框为同一个角色，画风统一，五官服装配色完全一致，8K 高清。 板块布局：画面左侧是角色大头胸像；右上角纯白背景全身立绘；右下角放 3 个细节特写小窗口，分别展示肩饰、腿部纹路、耳饰。
 
 【角色描述】 人物：女生，草木精灵，气质安静治愈 脸：皮肤白皙，浅绿色眼睛，额间淡粉色小花钿 头发：浅棕长卷发，带碎发，尖尖精灵耳朵 衣服：里面吊带中式连衣裙，外面单层轻薄短飘纱；裙摆不对称，一边长一边短，布料印藤蔓花瓣花纹 身上小装饰：细藤编项链 身体特征：胳膊上长淡淡的绿色藤蔓纹路 姿势：站姿，双手轻握一枝小花
【负面词】 畸形、五官扭曲、人体崩坏、多肢体、模糊、水印、多余文字

## 五、额外小自由度技巧

1. 视图可以砍：不想画背面，直接写【正面 + 侧面二视图】，不用强制三视图
2. 细节图数量随便改：2 个也行，5 个也行，只挑你觉得最重要的设计点
3. 可以删掉色卡、配饰框，不需要就不写进去
4. 还能调换板块摆放位置，比如把全身图放最上面，细节放左边

# 六、扩充板块
# 规则：全部是独立板块，想用就加、不需要直接删掉；可以自由指定摆放位置；同一张图里**不要一次性塞超过6个板块**，不然画面拥挤混乱。 分类：基础视图板块、细节拆解板块、辅助设计板块、草稿/动态板块、实验创意板块

## 一、基础视图板块（看角色整体外形，最常用）

- 大头胸像（头+肩膀，看五官、表情、发型头饰）
- 半身像（头到腰，看上身穿搭、肩饰、项链）
- 全身氛围感效果图：带简易背景、光影，角色带姿势，看整体气质
- 纯白底全身立绘：无背景、无特效，只看服装轮廓版型
- 多视图线稿：正面 / 侧面 / 背面；可自选2个（二视图）或者3个（三视图），甚至只单独要正面
- 局部特写全身裁切：比如只截取腰到脚，专门看腿部设计、鞋子、裙摆

## 二、细节拆解板块（放大重点设计，展示巧思）

- 服装面料特写：单独放大布料质感（薄纱、哑光硬布、鳞片纹理、羽毛）
- 饰品拆解特写：单独一件配饰放大（项链、耳坠、腰链、肩饰）
- 手部特写：手掌、手套、戒指、指甲造型
- 足部特写：袜子、绑带、鞋子设计
- 种族特征特写：龙角/精灵耳朵/兽耳/翅膀/鳞片的近距离特写
- 纹样印花特写：衣服上的暗纹、鱼鳞、藤蔓、冰裂纹单独放大

## 三、辅助设计板块（方便存档、配色、参考，适合存Obsidian）

- 配色色卡：4~6个纯色方块，锁定角色全套主色+点缀色
- 配饰平铺面板：所有首饰、武器、面具、道具整齐平铺在白底上
- 空白档案框：只有边框，**禁止AI生成任何文字**，留给你后续手写人设档案
- 材质参考小色块：区分不同面料（纱/金属/皮革/鳞片）的材质小样
- 尺寸比例参考线：角色旁边画简易身高标尺（用来对比角色身高）

## 四、草稿&动态板块（增加生动感，偏向原画前期设定）

- 动态速写小样：简单线稿，角色一个行走/抬手/跳跃的动态草稿
- 表情集小框：2~4个小头像，同一个角色不同表情（平静、浅笑、冷脸）
- 手部动作速写：几组不同手势草稿
- 服装折叠草稿：单独画裙摆、飘纱的动态褶皱参考

## 五、创意实验板块（适合做特色人设，按需少量选用，不常用）

- 变身前后对比小框：同一个角色，普通形态 / 觉醒形态并排对比
- **状态对比版（新增）**：同一个角色，两种状态并排对比——干燥版vs湿水版、战斗版vs日常版、穿铠甲vs穿便服。配局部细节放大，讲清楚哪里变了哪里没变
- 部件替换参考：同一件衣服的两种版本（有无外纱两种效果）
- 光效参考小样：角色发光部位单独演示（发光管线、宝石光晕）
- 轮廓剪影图：纯黑色角色剪影，快速看整体外轮廓好不好看

# ✅ 选板块的2条硬性小规则（防止画面爆炸）

1. 单张设定图，板块总数≤6个。比如：半身像 + 二视图 + 2个细节窗口 + 色卡，一共5个，刚好。
2. 同类不要重复堆：不要同时放「全身氛围感效果图」+「纯白全身立绘」，二选一就够。

## 举一个自定义搭配例子（测试新增板块）

挑选板块：半身像 + 正面+侧面二视图 + 手部特写 + 表情集（3个表情）+ 配饰平铺 布局描述：画面上方放半身像；左侧放二视图；右下角放手部特写+表情小框；最底部配饰平铺。

## 视频分镜设定板（完整版，做AI视频的时候用）

一张图搞定整个视频的设定，包含：
- 顶部：标题 + 段落信息（SEG/CUT/时长/画幅）+ 保留项 + 音频说明
- 左侧：角色设定区（每个角色三视图+脸部特写，编号对应）
- 中间：故事板区（5个分镜，每个标时间码+运镜方式）
- 右侧：道具/场景参考区（道具多角度+场景参考图）
- 底部横排：灯光/相机/配色/音频/情绪关键词/摄影笔记
- 还有：相机移动俯视图（从天上看镜头怎么走）

## 多人合影站位技巧（做群像插画的时候用）
- 高低错落，不站成一排，像朋友自然合影
- 中间站主角，旁边站配角，前后有层次
- 动作放松：拿咖啡、比耶、靠栏杆，不僵硬
- 背景有场景：公园/街道/校园，不是纯色背景
- 穿搭日常化：都是日常衣服，不夸张，有代入感
- 前景加虚化花枝/灯笼，拉开空间感
- 衣服颜色区分开，不撞色
- 道具多样化：团扇、花枝、墨镜，每人拿的不一样
- 层次感三招：①前景虚化→人物清晰→背景柔化，三层虚实；②两人在前两人在后，不站一个平面；③前景暗、人物亮、背景淡，颜色深浅拉开

## 建筑概念设定板（做场景/建筑设计的时候用）
一张图搞定整个建筑的设定，包含：
- 主视觉大图：建筑整体外观，放在中间最大
- 周边小板块：平面图、内部透视、细部节点、正立面、纵剖面、结构分析
- 概念演化：从简到繁的步骤小图
- 配色统一：主色+点缀色，比如蓝白金
- 排版像建筑图纸，留白多，板块对齐

### 建筑立面细节（折叠/转折处）
- 壁龛里站金色小人雕像
- 一层叠一层的小尖塔、小装饰柱
- 金色装饰线顺着结构转折走，不是平涂一条线
- 蓝色长窗嵌在白墙里，窗框勾金边
- 立面是凹凸的，有进深层次，不是平面一块

适合：做AI短视频/AI动画的时候，一张图把所有设定都讲清楚。

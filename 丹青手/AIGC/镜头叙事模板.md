# 一、镜头叙事基础概念

1. **单镜头叙事**：整张图只有一个镜头、一个画框。一整个定格画面，同时包含人物、动作、宏大环境，靠单张画面讲故事。 优点：氛围感冲击力强；缺点：没法同时展示三视图、服装背面等细节。 例：你发的女统帅战场全景图，广角仰拍，定格大战前的瞬间。
2. **多镜头叙事（多格分镜）**：**同一张画布，多个独立小画框**，每个画框是单独机位镜头。 可以搭配：全景主镜头 + 手部特写 + 眼部特写。一张图兼顾故事氛围感 + 角色细节展示。

   **视频分镜标准格式（做AI视频的时候用）：**
   - 每个分镜标时间码：0.0-3.7、3.7-8.4...
   - 每个分镜标运镜方式：推近、弧线推、俯视、平移...
   - 每个分镜标保留项：保留哪个角色、保留哪个穿搭
   - 底部加相机移动俯视图：从天上看镜头怎么走
 
 两种都属于镜头叙事，区别只是镜头数量。


### ✅ 镜头叙事创作[[工作流]]（大白话版）

1. 想好故事瞬间：角色是谁，正在发生哪一件事（优先想故事，再设计穿搭）
2. 选拍摄角度（机位）
    - 仰拍（从下往上）：人物显得强大威严，适合统帅、神明、强者
    - 平视：面对面的感觉，适合安静、对话类画面
    - 俯拍（从上往下）：上帝视角，适合大军、宏大风景，人物显得渺小
    - 特写：只拍脸/手，专门放大情绪
3. 划分画面三层结构：**近处（前景）、中间（主角）、远处（背景）**
    - 前景：离镜头最近的小东西（花瓣、碎冰、武器前端），制造隔着东西观察的临场感，可以轻微模糊。少量即可，别挡住主角。
    - 中景：主角，视觉核心。
    - 远景：远处环境（城池、山脉、云海、星空），一层叠一层，像千层蛋糕。

4. **逆光剪影技巧**（战斗镜头专用）：人物在强光前面，大部分是暗的，只有轮廓和发光的武器/眼睛特别突出。背景亮、人物暗，对比强烈，特别有战斗感。再加一点飞散的碎片/火星，动感直接拉满。

5. **丁达尔光技巧**（氛围感专用）：阳光从树叶缝隙/云层里透下来，一束一束的光柱。不用多，2-3束就够了，氛围感直接拉满。适合安静、治愈、神圣的场景。

6. **季节氛围套装**（做氛围图直接抄）：
   - 秋日：金黄树叶+落叶+长椅+湖边+安静的动物
   - 春天：樱花+花瓣+草地+野餐
   - 夏天：树荫+冰棍+风扇+蝉鸣
   - 冬天：雪+围巾+热饮+暖黄灯光

7. **画里画外互动创意**（做创意短视频用）：
   - 手里拿画/照片/手办，让画里的元素和现实场景对齐
   - 借现实里的光，刚好照在画里的关键位置（眼泪/眼睛/剑），让它"发光"
   - 黑白线稿+局部发光，情绪反差拉满

8. **圣物场景光效**（做神圣/神秘场景用）：
   - 圣物（剑/法杖/水晶）插在石台中央，自身发光
   - 顶光从上方透下来，2-3束就够了，不要多
   - 前景加石头/草，中景圣物，远景洞壁/树林，三层结构

9. **日落场景公式**（做浪漫/孤独氛围用）：
   - 太阳在海平面/地平线中央，拉出一条金色光路到镜头前
   - 天空用粉紫/橙红色调，低饱和一点，别太艳
   - 加个小元素（船/鸟/人）当比例尺，不然太空

10. **咬东西创意镜头**（做浪漫/情绪特写用）：
   - 人物嘴里咬着一块东西（布料/花瓣/丝带/手套）
   - 咬的东西带光/带颜色，和背景呼应
   - 半脸特写，只拍眼睛和嘴，氛围感拉满

11. **半脸特写技巧**（做神秘感/氛围感用）：
   - 只露一只眼睛/半张脸，比全脸更有神秘感
   - 遮挡物要和主题呼应（玫瑰挡脸配暗黑、羽毛挡脸配天使）
   - 眼睛细节拉满：渐变瞳孔+星点+长睫毛

12. **错位透视创意**（做创意摄影/错觉画面用）：
   - 利用近大远小，让远处的人和近处的道具看起来互动
   - 借位道具：相框里伸出手、镜子里伸出脚、路牌当伞
   - 前景遮挡：水珠/碎玻璃/花瓣挡镜头，增加动感
4. 从【人设[[零件池]]】挑选角色服装、饰品（穿搭要匹配角色身份和故事场景）
5. 增加光影、层次相关描述，拼成完整提示词

## 二、光影层次感怎么做

核心：**画面不能亮度完全一样，分4档亮度，像舞台追光，重点照亮主角**

1. 主光：主要光源，重点打亮人物脸、肩、武器，主角是整张图最亮的地方，把人物从背景分离出来。
2. 环境次光：远处背景带淡淡的微光，亮度一定要弱于主角，不能抢主角。
3. 环境反光：阴影不是死黑一片。暗处会染上环境的颜色（紫色环境，阴影就带紫调）。
4. 硬光/软光
    - 软光：光线柔和，阴影过渡顺滑。适合宏大奇幻、仙气场景。
    - 硬光：光影边界锋利，闪电、直射阳光，适合紧张战斗画面。

规则：**整张图只能有1个主光源**，多个强光会互相打架，画面变脏。

 提示词片段参考： 主光源来自远处地平线的黄昏霞光，光线柔和，重点照亮人物主体，人物为画面最亮区域；远处云海和浮空城带有微弱环境紫光；阴影不是死黑，笼罩淡淡的紫色环境反光；金属铠甲和宝石有高光反光，薄纱透光，明暗过渡柔和。

## 三、除光影之外，增加画面层次的5种手段

核心原理：拉开**近、中、远**的差距，让眼睛能看出物体距离，避免画面扁平。

1. **虚实变化（清晰度）** 前景轻微模糊；中间主角最清晰；远景柔和虚化。 ❌ 坑：所有物体全部高清，画面会扁平没有深度。
2. **色彩深浅（空气透视）** 近处颜色鲜艳饱和度高；主角色彩最饱满；远处景物颜色变浅、发灰、饱和度降低。（远处像蒙一层薄雾）
3. **物体互相遮挡** A挡住B，立刻分出前后。例：花瓣挡武器边缘，云雾盖住城池底座。 ❌ 坑：不要遮挡主角脸部和核心设计。
4. **近大远小（尺寸对比）** 同样物体，近大远小。近处物体看着更大，越远越小，营造空间延伸感。
5. **材质质感区分** 多种质感搭配：半透明薄纱、金属、花瓣、云雾、岩石，质感区分，画面不单调。

提示词片段参考： 前景：虚化、高饱和度元素，轻微遮挡；中景主体清晰，色彩饱满；远景物体缩小，颜色变浅发灰，云雾遮挡远处景物，多种材质并存，近大远小。

## 四、通用避坑清单

1. 不要一次性堆满所有层次元素，挑选2个左右就够用，堆太多画面杂乱。
2. 前景只放一点点，放多了直接盖住主角。
3. 远景不是元素堆越多层次越好，杂乱元素反而毁掉画面。
4. 光源只能选1个主光源，不要多个强光。

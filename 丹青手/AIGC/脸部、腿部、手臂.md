# Obsidian 笔记：角色外貌描写｜脸部 + 四肢 + 身形（AI 绘图提示词，大白话）

关联：：只写原画风格自然轮廓描写，不低俗，侧重轮廓、线条、质感，减少 AI 人体崩坏，不写夸张直白词汇

## 一、脸部描写（重点！决定角色气质，优先写）

写作顺序：脸型 → 五官整体 → 眼睛（最关键）→ 眉毛、鼻子、嘴唇 → 皮肤、发型辅助

### 脸型选项（直接复制）

- 鹅蛋脸：鹅蛋脸型，线条柔和流畅，圆润下颌
- 瓜子脸：瓜子小脸，下颌线条纤细利落
- 圆脸：圆润幼态圆脸，下颌柔和，少女感
- 冷感长脸：偏长脸型，下颌清晰利落，成熟威严感（适合统帅）

### 眼睛（气质核心，必写）

格式：眼型 + 瞳孔颜色 + 眼神 + 眼妆 / 细节

- 杏眼：杏眼，瞳孔紫色，眼神清冷沉静，长睫毛，淡淡的细眼线
- 桃花眼：桃花眼，眼尾微微上挑，温柔含笑，长睫毛
- 丹凤眼：丹凤眼，眼尾上扬，眼神锐利坚定，冷感（适合统帅强者）

### 其余面部

- 眉毛：细长柳叶眉 / 平直眉 / 剑眉（英气）
- 鼻子：鼻梁纤细挺直，鼻尖柔和
- 嘴唇：薄唇，唇线清晰，淡淡冷感；或是饱满柔唇，浅浅微笑
- 皮肤：细腻光滑皮肤，通透肤质，淡淡的自然肤色，面部柔和光影

✅完整脸部示例（女统帅）

> 鹅蛋长脸，下颌线条利落，丹凤眼，紫色瞳孔，眼神冷静威严，长睫毛，细长柳叶眉，挺直细鼻梁，薄唇，细腻通透的皮肤

## 二、手臂描写

思路：先写手臂骨架粗细，再写线条，搭配配饰 / 铠甲

- 纤细少女款：手臂纤细修长，线条柔和
- 力量成熟款：手臂修长，线条紧致流畅，带有力量感 搭配示例：修长手臂，佩戴金属臂甲，手臂线条紧致流畅

## 三、手部描写（超级加分项，特写镜头专用）

重点写手指形态，原画很看重手

- 纤细修长手指，指尖精致，指甲短而干净
- 手指修长，指尖轻握武器，手部线条优美

> 适合放在镜头叙事的手部特写小框

## 四、腿部描写

核心：写腿型 + 长度，靠裙摆 / 高开叉 / 袜子衬托轮廓，不要直白局部特写 ✅推荐写法：

1. 纤细款：双腿修长纤细，线条顺滑柔和
2. 匀称成熟款：双腿修长，线条匀称流畅，健康紧致线条 搭配服装写法（效果最好）

- 高开叉长裙，露出修长匀称双腿，线条流畅柔和
- 长款纱裙，隐约露出纤细小腿

❌避坑：不要单独聚焦局部，结合服装去描述，画面更自然，降低崩坏概率
